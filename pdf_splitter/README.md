# PDF 분할 프로그램

## 실행 방법

1. 바탕화면의 `PDF 분할 도구` 바로가기를 더블클릭합니다.
2. PDF 파일을 선택합니다.
3. 저장 폴더를 선택합니다.
4. 오른쪽 미리보기에서 PDF 페이지를 확인합니다.
5. 분할 방식을 선택한 뒤 `PDF 분할 시작`을 누릅니다.

CMD 창 없이 직접 실행하려면 `run_pdf_splitter_no_cmd.vbs`를 사용합니다.
필요한 라이브러리를 다시 설치해야 할 때만 `run_pdf_splitter.cmd`를 사용합니다.

## 디자인 디케이

이 프로그램은 `디자인 디케이` 기준을 적용합니다.

- 기준 색상: `#0077C0`
- 진한 강조색: `#005B96`
- 연한 배경색: `#EAF5FC`
- DK 로고 아이콘 사용

앞으로 이 프로젝트에서 `디자인 디케이`, `DK 디자인`, `디케이 스타일`, `DK 로고 색깔`처럼 말하면 같은 색상 계열을 적용합니다.

## 분할 방식

- 모든 페이지를 1페이지씩 분할
- 범위 지정 분할

## 미리보기

PDF를 선택하면 첫 페이지가 오른쪽에 표시됩니다.
하단에는 현재 페이지가 `-1-` 형식으로 표시됩니다.
미리보기 화면을 클릭한 뒤 마우스 휠을 위/아래로 움직여 페이지를 넘길 수 있습니다.
`이전`, `다음` 버튼으로도 페이지를 넘겨 확인할 수 있습니다.

범위 지정 예시:

```text
1-3, 4, 5-7
```

위 예시는 `1~3페이지`, `4페이지`, `5~7페이지`를 각각 별도 PDF로 저장합니다.
