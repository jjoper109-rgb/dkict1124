# DK 품의서 임시보관 자동화 확장 프로그램

크롬 또는 엣지에서 압축해제된 확장 프로그램으로 불러와 사용하는 자동화입니다.

## 설치

1. 브라우저 주소창에 `chrome://extensions` 입력
   - 엣지는 `edge://extensions`
2. `개발자 모드` 켜기
3. `압축해제된 확장 프로그램을 로드` 클릭
4. 이 폴더 선택:
   `C:\Users\221028\Documents\디케이 서버\디케이 자동화\gw-approval-extension`

## 설정

1. 확장 프로그램 상세 화면에서 `확장 프로그램 옵션`을 엽니다.
2. 사번, 비밀번호, 품의서 내용을 입력합니다.
3. `로그인 화면에서 자동 로그인`을 켭니다.
4. 임시보관까지 자동으로 하려면 `입력 후 임시보관까지 자동 실행`을 켭니다.
5. `저장`을 누릅니다.

## 실행

그룹웨어 로그인 주소로 이동합니다.

`http://gw.e-dk.co.kr/`

설정이 채워져 있으면 다음 흐름으로 진행됩니다.

1. 로그인
2. 품의서 양식 선택 화면 이동
3. 설정한 품의서 양식 선택
4. 작성 화면 입력
5. 임시보관

## 주의

- `결재상신`은 자동으로 누르지 않습니다.
- 설정값이 비어 있으면 입력/임시보관 단계가 중단됩니다.
- 비밀번호는 브라우저 로컬 확장 프로그램 저장소에 저장됩니다.
